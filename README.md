# Origo

App web para seguir al bebé. Página estática (sin servidor ni compilación), publicada con GitHub Pages.

- `index.html`: estructura de la página.
- `css/origo.css`: estilos.
- `js/01-config.js` … `js/13-inicio.js`: el código, por bloques, en orden de carga (detalle en `TRASPASO.md` → «Archivos»).
- `assets/`: logo, iconos e ilustraciones de la escena.
- `sw.js` y `manifest.webmanifest`: instalación en el móvil y uso sin conexión.
- `TRASPASO.md`: guía técnica y estado del proyecto.
- `reglas-firestore.txt`: reglas de seguridad de Firestore.
- `qa/`: pruebas automáticas (Chromium).
